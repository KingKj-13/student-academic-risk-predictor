# Student Academic Risk Prediction and Early-Warning System

A web application that estimates whether a student is at **Low**, **Medium** or **High** academic risk,
explains which figures are driving the estimate, and puts at-risk students at the top of a teacher's dashboard.

> The bundled data is **synthetic** (generated by `generate_data.py`). Results describe the software and the
> method, not any real students. The output supports a teacher's judgement and must not be used as the only
> basis for a decision about a student.

## Features

- Single-student prediction form and bulk CSV upload with row-by-row validation
- Teacher dashboard: counts per risk level, averages, charts, search and filter
- Student page: latest result, contributing factors, suggested actions, history and trend chart
- Early-warning alert when a student moves into High risk (optional email digest)
- SQLite storage, REST API with interactive documentation at `/docs`
- Optional password protection

## Quick start

Requires Python 3.11 or newer.

**Windows:** double-click `run.bat` (or run it in a terminal).

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python train.py                 # creates models/risk_model.joblib
uvicorn main:app --reload
```

Open <http://127.0.0.1:8000>. To try bulk upload, download the sample file from the upload page.

Run `python train.py` again after changing library versions: the saved model is only guaranteed to load with
the scikit-learn version that created it.

`python generate_data.py` recreates the raw dataset (same seed, same rows).

## Model results

500 synthetic students after cleaning (275 Low, 135 Medium, 90 High), 80/20 stratified split.
Hyper-parameters and the final model were chosen by 5-fold cross-validation on the training split.

| Model | Accuracy | Macro F1 | High-risk precision | High-risk recall |
|---|---|---|---|---|
| **Logistic Regression** (selected) | 0.82 | 0.79 | 0.73 | 0.89 |
| Decision Tree | 0.76 | 0.73 | 0.70 | 0.78 |
| Random Forest | 0.80 | 0.77 | 0.70 | 0.89 |
| Baseline (always "Low") | 0.55 | 0.24 | 0.00 | 0.00 |

The test split has 100 students (18 High), so differences of a few points are not conclusive.
All figures are in `data/processed/metrics.json`.

## API

| Method | Path | Purpose |
|---|---|---|
| POST | `/api/predict` | Predict one student (JSON) |
| POST | `/api/upload` | Predict a CSV file (multipart field `file`) |
| GET | `/api/sample-csv` | Example CSV |
| GET | `/api/students` | Latest result per student (`risk`, `search`, `limit`, `offset`) |
| GET | `/api/students/{id}` | One student with history |
| DELETE | `/api/students/{id}` | Delete a student and their history |
| GET | `/api/dashboard-stats` | Counts and averages |
| GET | `/health` | Health check |

Example:

```bash
curl -X POST http://127.0.0.1:8000/api/predict -H "Content-Type: application/json" -d '{
  "student_id": 101, "name": "Test Student", "attendance_pct": 55, "internal_marks": 38,
  "study_hours_weekly": 5, "past_failures": 2, "assignment_score": 42,
  "gender": "Male", "extracurricular": "No"
}'
```

## Deployment

`render.yaml` describes a Render web service. Create it from the repository, then set `APP_USERNAME` and
`APP_PASSWORD`; the app refuses to start without them.

Notes:

- A free instance has no permanent disk, so `students.db` is lost when it restarts or redeploys.
- Use HTTPS only (Render provides it). Basic authentication is not safe over plain HTTP.
- One shared password is enough for a demonstration, not for real student records.

## Email alerts

Set `SMTP_HOST`, `SMTP_PORT`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `ALERT_FROM` and `ALERT_TO` as environment
variables (see `.env.example`). Without them, alerts appear in the app and in the server log only.
For Gmail, use an app password. Never commit credentials.

## Responsible use

- **Synthetic data:** the labels come from a rule written for this project, so the scores show that the models
  can recover that rule through noise. They say nothing about accuracy on real students.
- **Decision support only:** a teacher decides what, if anything, to do.
- **Confidence is a probability,** not certainty. Calibration was measured (see `eval_calibration.png`).
- **Fairness:** gender is stored but deliberately not used by the model; it is used only to compare High-risk
  recall between groups.
- **Privacy:** records are personal data. Restrict access, collect only what is needed, delete on request.

## Limitations

- Not validated on real institutional data
- One shared login, no teacher accounts or audit trail
- Contributing factors show how the model reacts to a change in one input; they are not proven causes
